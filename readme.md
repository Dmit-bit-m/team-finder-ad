# TeamFinder — Вариант 3

Платформа для поиска участников в Pet-проекты. Вариант 3: навыки проектов и фильтрация проектов по навыкам.

## Быстрый старт для ревьюера

### 1. Запустить базу данных

```bash
docker compose up -d
```

База PostgreSQL поднимается на порту **5436** (чтобы не конфликтовать со стандартным 5432).

### 2. Создать и активировать виртуальное окружение

```bash
python -m venv venv

# Windows (PowerShell):
venv\Scripts\Activate.ps1

# Linux/Mac:
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Применить миграции

```bash
python manage.py migrate
```

### 5. Создать тестовых пользователей и проекты

```bash
python manage.py create_test_data
```

Это создаст:

| Email | Пароль | Роль |
|---|---|---|
| alice@example.com | testpass123 | Обычный пользователь |
| bob@example.com | testpass123 | Обычный пользователь |
| carol@example.com | testpass123 | Обычный пользователь |
| david@example.com | testpass123 | Обычный пользователь |
| admin@example.com | adminpass123 | Суперпользователь |

У каждого пользователя есть минимум один проект. У проектов назначены навыки.

### 6. Запустить сервер

```bash
python manage.py runserver
```

Сайт доступен по адресу: **http://localhost:8000**

Админ-панель: **http://localhost:8000/admin**

## Переменные окружения (.env)

Файл `.env` уже создан и настроен для локальной разработки. Ориентируйтесь на `.env_example`.

| Переменная | Значение по умолчанию |
|---|---|
| DJANGO_SECRET_KEY | (задан) |
| DJANGO_DEBUG | True |
| POSTGRES_DB | team_finder |
| POSTGRES_USER | team_finder |

| POSTGRES_PORT | 5436 |

## Структура проекта

```
team_finder/      — конфигурация Django
users/            — приложение пользователей (кастомная модель User, формы, вьюхи)
projects/         — приложение проектов (Project, Skill, формы, вьюхи)
templates_var3/   — HTML-шаблоны для варианта 3
static/           — CSS, JS, изображения
media/            — загруженные файлы (аватарки)
```

## Реализованный функционал (Вариант 3)

- Кастомная модель пользователя с авторизацией по email
- Автогенерация аватара (первая буква имени на цветном фоне) при регистрации
- Регистрация, вход, выход, смена пароля
- Редактирование профиля с валидацией телефона и GitHub-ссылки
- CRUD проектов (создание, редактирование, завершение)
- Участие в проектах (toggle)
- Модель `Skill` — навыки проектов (M2M)
- Добавление/удаление навыков проекта без перезагрузки страницы (AJAX + автодополнение)
- Фильтрация проектов по навыку (`?skill=`)
- Пагинация (12 элементов на странице) для проектов и пользователей
- Права доступа: гость / авторизованный пользователь / администратор
- Кнопка «Поделиться» (копирует ссылку в буфер обмена)
- Админ-панель для управления пользователями и проектами
